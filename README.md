# Illustration Portfolio

Live Website: https://andersonmaia.github.io/portfolio-art/

Portfolio website showcasing my illustration work.

## Objectives of the Project

- Practice building a full, responsive website, using only the basics (HTML, CSS and vanilla Javascript)
- Practice using JSON files to store, organize and sort through data
- Have a portfolio to showcase the artwork I've produced in 10 years as a professional illustrator for RPG publishers

## Features

- Responsive gallery layout with masonry style image grid (inspired by Pinterest)
- Image modal viewer
- Filtering by year (with other metadat added to each image entry on the JSON file for possible filtering expansion)
- Dark / light mode
- Multilanguage support (Brazilian Portuguese and English)
- Personalized svg icons made in Inkscape

## Built with

- HTML
- CSS
- Vanilla JavaScript
